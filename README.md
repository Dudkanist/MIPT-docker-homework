# Bio-Gene Tracker API

## Описание
Это простое FastAPI приложение для хранения названий генов и их описаний. 
Оно создано в рамках учебного задания по Docker для демонстрации контейнеризации биоинформатического ПО.

## Вариант задания
Выбран **Вариант 3**, реализовано:
1. Проброс портов, доступ из браузера.
2. Настройка через переменные окружения.
3. Сохранение данных между перезапусками через Named Volume.

## Инструкция по запуску

1. **Сборка образа:**
	bash docker build -t mantsevich_docker .
2. **Внесение изменений:**
	http://localhost:8080/docs
